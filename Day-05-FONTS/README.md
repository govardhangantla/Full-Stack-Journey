# 🖋️ 1. CSS Fonts

CSS fonts are used to control the appearance of text on a webpage.

We can change:

- Font family
- Font size
- Font weight
- Font style
- Text transformation
- Text decoration
- Line height

---

## 🔤 Font Family

The `font-family` property specifies which font should be used.

Example:

```css
p {
    font-family: Arial, sans-serif;
}

h1 {
    font-family: Georgia, serif;
}
