# Day 4 - CSS Selectors 🚀

Today I learned about **CSS Class Selectors** and **CSS ID Selectors** as part of my Full Stack Development journey.

---

## 📚 Topics Learned

### 1. CSS Class Selectors

A class selector is used to style one or more HTML elements.

### Syntax

```css
.className {
    property: value;
}
### 1. CSS Class ID Selectors
### Syntax
#className {
    property: value;
}
