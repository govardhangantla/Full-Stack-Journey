# CSS Layout & Positioning

This project covers important CSS concepts used to control the layout, position, and arrangement of elements on a webpage.

- CSS Positioning
- CSS Float
- CSS Clear
- CSS Display Property
- Block
- Inline
- Inline-block
- Flexbox
- CSS Grid

# 1. CSS Positioning

The CSS `position` property controls how an element is positioned on a webpage.

## Types of Positioning

### Static

`position: static` is the default position of an element.

```css
.box {
    position: static;
}
