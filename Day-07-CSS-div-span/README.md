# CSS Div and Span: Product Card Example

A beginner-friendly demonstration of web page structuring using HTML and CSS. This project illustrates the fundamental differences between block-level elements and inline elements by building a simple, styled product card.

## 📝 Description

In HTML, understanding how elements take up space is crucial for building layouts. This project provides a practical example of:
*   **Block-level elements (`<div>`)**: Acting as the main container (`.product-card`) that takes up full width and forces new lines.
*   **Inline elements (`<span>`)**: Acting as text modifiers (`.highlight`, `.price`, `.stock-status`) that style specific content without breaking the flow of the text.

## 📁 Files Included

*   `index.html` - The structural markup containing the `<div>` and `<span>` tags.
*   `styles.css` - The visual styling rules linking to the HTML to create the final card design.

## 🚀 How to Run

No servers or complex setups are required. 

1. Create a new folder on your computer.
2. Save the `index.html` and `styles.css` files into this folder.
3. Double-click the `index.html` file to open it in your default web browser.

## 🧠 Key Concepts Covered

*   **HTML Structure**: Grouping related content into logical containers.
*   **Linking CSS**: Using the `<link>` tag to connect an external stylesheet.
*   **Block vs. Inline**: Seeing firsthand how `<div>` stacks vertically and `<span>` sits horizontally side-by-side.
*   **CSS Selectors**: Targeting elements using class names (e.g., `.price`, `.product-card`).
