# CSS Box Model – Basic & Advanced

## 📌 Overview

In this project, I learned the **CSS Box Model** from basic to advanced concepts.

The CSS Box Model explains how every HTML element is structured using:

**Content → Padding → Border → Margin**

I also learned advanced properties such as `box-sizing`, margin spacing, and `border-spacing`.

---

## 📚 Topics Covered

### 🔹 Basic CSS Box Model

The basic CSS Box Model contains four parts:

1. **Content** – The actual text or element content.
2. **Padding** – Space between the content and border.
3. **Border** – The boundary around the element.
4. **Margin** – Space outside the border.

        Margin
    ┌───────────────┐
    │    Border     │
    │  ┌─────────┐  │

    │  │ │Content│ │  │
