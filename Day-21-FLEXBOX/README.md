# Flexbox Practice 🚀

This project is created to learn and practice **CSS Flexbox**, a modern CSS layout system used to arrange elements in rows and columns.

The project contains practical examples of Flexbox concepts such as direction, alignment, wrapping, flexible sizing, navigation bars, and card layouts.

---

## 📚 Topics Covered

- Flexbox Introduction
- Flex Container and Flex Items
- `display: flex`
- Flex Direction
- Main Axis and Cross Axis
- `justify-content`
- `align-items`
- `flex-wrap`
- `flex: 1`
- `gap`
- Responsive Flexbox
- Navigation Bar using Flexbox
- Card Layout using Flexbox

---

## 🎯 What is Flexbox?

**Flexbox (Flexible Box Layout)** is a CSS layout system that makes it easier to arrange and align elements inside a container.

To activate Flexbox:

```css
.container {
    display: flex;
}
