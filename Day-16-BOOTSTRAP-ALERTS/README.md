# Bootstrap Alerts 🔔

## 📌 Introduction

Bootstrap Alerts are ready-made components used to display important messages and notifications to users.

They are useful for showing:

- ✅ Success messages
- ❌ Error messages
- ⚠️ Warning messages
- ℹ️ Information messages

---

## 🧩 Basic Alert

```html
<div class="alert alert-primary">
    This is a primary alert.
</div>
