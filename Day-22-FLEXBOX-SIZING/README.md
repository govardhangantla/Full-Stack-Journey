# 📦 Flexbox Sizing – Flex Grow, Shrink & Basis

This project is a hands-on practice of **Flexbox Sizing** in CSS.

The main goal is to understand how Flexbox controls the size of flex items and how elements grow, shrink, and receive an initial size depending on the available space.

---

## 🚀 Topics Covered

- `flex-grow`
- `flex-shrink`
- `flex-basis`
- `flex` shorthand
- Flexible layouts
- Responsive card layouts
- Three-column layouts
- Responsive navigation bars

---

## 📌 1. Flex Grow

`flex-grow` controls how much a flex item can **grow** when extra space is available.

```css
.item1 {
    flex-grow: 1;
}

.item2 {
    flex-grow: 2;
}
