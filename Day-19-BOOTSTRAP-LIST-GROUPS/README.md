# Bootstrap List Group

## Introduction

Bootstrap List Group is used to display a series of items in a clean and organized list.

Bootstrap provides predefined classes to easily style list items.

## Basic List Group

```html
<ul class="list-group">
    <li class="list-group-item">HTML</li>
    <li class="list-group-item">CSS</li>
    <li class="list-group-item">JavaScript</li>
    <li class="list-group-item">Bootstrap</li>
</ul>
