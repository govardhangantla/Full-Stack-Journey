# 🃏 Bootstrap Cards

## 📌 Introduction

Bootstrap Cards are ready-made components used to display content inside a structured box.

Cards are commonly used for:

- 💻 Projects
- 🛍️ Products
- 👤 Profiles
- 📚 Courses
- 📰 Blog posts

---

## 🧩 Basic Card

```html
<div class="card">
    <div class="card-body">
        <h5 class="card-title">Java</h5>
        <p class="card-text">Learning Java and DSA.</p>
        <button class="btn btn-primary">Learn More</button>
    </div>
</div>
