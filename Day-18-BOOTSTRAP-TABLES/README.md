# Bootstrap Tables 📊

## Introduction

Bootstrap Tables are used to display data in rows and columns with clean and responsive styling.

Bootstrap provides predefined classes to easily customize tables.

## Basic Table

```html
<table class="table">
    <thead>
        <tr>
            <th>Name</th>
            <th>Course</th>
            <th>Marks</th>
        </tr>
    </thead>

    <tbody>
        <tr>
            <td>Govardhan</td>
            <td>CSE</td>
            <td>85</td>
        </tr>
    </tbody>
</table>
