# Day 10 - Bootstrap

## Topics Learned

### 1. What is Bootstrap?

Bootstrap is a free and open-source front-end CSS framework.

It provides ready-made CSS styles and components that help developers build websites faster and responsively.

### 2. Bootstrap Installation

Bootstrap can be added to a project using a CDN.

The Bootstrap CDN link is added inside the `<head>` section of the HTML file.

```html
<link rel="stylesheet"
href="https://cdn.jsdelivr.net/npm/bootstrap@5.2.3/dist/css/bootstrap.min.css">
