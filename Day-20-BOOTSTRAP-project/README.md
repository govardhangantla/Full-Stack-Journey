# Bootstrap Final Project 🚀

## 📌 Project Overview

This project is a responsive developer portfolio website built using **HTML and Bootstrap 5**.

The main purpose of this project is to practice and combine the important Bootstrap concepts learned throughout the Bootstrap course into one complete project.

## 🛠️ Technologies Used

- HTML5
- Bootstrap 5
- Bootstrap Grid System
- Bootstrap Utilities

## 📚 Bootstrap Concepts Used

This project combines the following concepts:

- Container
- Grid System
- Responsive Columns
- Navbar
- Buttons
- Typography
- Spacing Utilities
- Flexbox Utilities
- Cards
- Badges
- Progress Bars
- Tables
- List Groups
- Forms
- Responsive Design
- Utility Classes
- Footer

## 🖥️ Project Sections

### 1. Navbar

A responsive navigation bar with links to:

- Home
- About
- Skills
- Projects
- Contact

### 2. Hero Section

Introduces the developer with:

- Name
- Developer role
- Short description
- Call-to-action buttons

### 3. About Section

Contains a short introduction about the developer and their interests.

### 4. Skills Section

Displays technical skills using Bootstrap cards and badges.

### 5. Learning Progress

Uses Bootstrap progress bars to display learning progress.

### 6. Projects Section

Displays projects using responsive Bootstrap cards.

### 7. Education Section

Uses a Bootstrap table to display educational information.

### 8. Learning List

Uses Bootstrap List Group and Badges to display currently learning technologies.

### 9. Contact Section

Contains a responsive contact form using Bootstrap form components.

### 10. Footer

Contains developer information and copyright text.
